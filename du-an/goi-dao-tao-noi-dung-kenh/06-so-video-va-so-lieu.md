# Mẫu 06 · Sổ video và sổ số liệu (Bài 11, 12)

> Dùng bảng tính (Google Sheets, Excel, Numbers) hoặc ghi chú. Mỗi video một dòng. Tuyến C: để AI tự ghi vào file `so-video.md` trong thư mục làm video.

## Sổ video
| Ngày quay | Tên tập | Ý số (kho) | Điểm lọc | Kênh | Ngày đăng | Link | Trạng thái |
|---|---|---|---|---|---|---|---|
| | | | | | | | đã quay / đang dựng / chờ đăng / đã đăng / cất kho |

## Sổ số liệu
Ghi sau 24 giờ và sau 7 ngày. Chỉ số chính là cột "Hành động" (theo mẫu 01: tin nhắn, đơn, lịch hẹn…).

| Tên tập | Mốc | Lượt xem | Xem trung bình (giây) | % giữ chân | Bình luận | Hành động | Kết quả / Vấn đề | 1 điều sửa cho video sau |
|---|---|---|---|---|---|---|---|---|
| | 24 giờ | | | | | | | |
| | 7 ngày | | | | | | | |

## Nhìn lại cuối tuần (15 phút)
1. Tuần này đăng mấy video? Đúng nhịp không?
2. Video nào có **Hành động** cao nhất? Vì sao (ý, câu mở, tiêu đề, giờ đăng)?
3. **Vấn đề** lớn nhất: do thực thi (quay, dựng, đăng) hay do ý? Kiểm thực thi trước.
4. Đã sửa gì vào hồ sơ / lời dặn tuần này?
5. 4 ý quay tuần sau (từ kho ý).
