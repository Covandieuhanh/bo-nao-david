# Mẫu 02 · Phiếu lọc và kho ý (Bài 2)

## Phiếu lọc: chấm một ý hoặc một video đã quay
Học viên chấm 0–2 cho mỗi tiêu chí (2 = rõ, 1 = có nhưng mờ, 0 = không).

| # | Tiêu chí | Điểm | Lý do một dòng |
|---|---|---|---|
| 1 | **Đúng mục tiêu kênh** (mẫu 01, phần Tiền) | | |
| 2 | **Có ích cho người xem** (liên quan tới 1 trong 3 vấn đề lớn) | | |
| 3 | **Có việc làm theo** (người xem làm được ngay) | | |
| 4 | **Thu hút bình luận** (có câu mở giữ người xem và chỗ hỏi tự nhiên) | | |
| 5 | **Người nói đáng tin** (chuyện thật, trải nghiệm thật) | | |

**Tổng ……/10**: 9–10 thì làm đủ bộ (bản dài + clip + bài viết) · 7–8 làm bản chính · 5–6 chỉ clip / bài ngắn · tối đa 4 cất kho hoặc bỏ.

- **3 phần:** Vấn đề …… · Giải pháp …… · Thực thi …… (thiếu phần nào: ……)
- **Ranh giới:** không chạm / chạm ở …… thì xử lý: ……
- **Dẫn tới đâu:** vấn đề người xem dẫn tới sản phẩm / dịch vụ nào, rồi tới câu mời nào
- **Đăng:** kênh …… · ngày …… · kiểu bài: chia sẻ / gợi mở / mời hành động

## Kho ý
Mỗi đợt, học viên chọn 4 ý điểm cao nhất để quay. Xen kẽ: cứ 10 bài có khoảng 4 bài chia sẻ, 4 bài gợi mở, 2 bài mời hành động.

| # | Vấn đề của người xem | Ý video (một câu) | Điểm | 3 dòng chuẩn bị đã có? | Trạng thái |
|---|---|---|---|---|---|
| 1 | | | | | ý tưởng / đã quay / đã dựng / đã đăng |
| 2 | | | | | |
| 3 | | | | | |

## 3 dòng chuẩn bị trước khi quay
1. Khoảnh khắc người xem thấy "đúng là mình": ……
2. Vướng mắc và cách đã tháo gỡ (chuyện thật): ……
3. Câu hỏi / việc người xem mang về: ……
